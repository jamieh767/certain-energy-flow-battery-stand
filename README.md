# Certain Energy: Mn–H₂ flow battery

This repository contains a static HTML presentation for the Certain Energy manganese–hydrogen flow battery concept.

## Overview

The page showcases the system concept, the chemistry inside a cell, power and energy relationships, and a Humber example scenario. It is designed as a single-file interactive web page with tabbed sections and animated visual explanations.

## Files

- `certain-energy-flow-battery-stand.html` — the complete standalone HTML page
